# ОТДЕЛЕНИЕ: НИЖЕ

> Third-person **action-horror visual novel** на **Godot 4.4+**.
> Камера — как в *The Binding of Isaac* (наклон −52°, комнатный snap, боевой отъезд).
> Бой — как в *ULTRAKILL* (кровь = здоровье, стиль = валюта, парирование = жизнь).
> Сюжет — психиатрическая больница, которая является чистилищем, нарисованным
> двенадцатилетней пациенткой. Игрок в финале узнаёт, что он не она.

## Столпы

1. **БОЛЬ — ТОПЛИВО.** Лечит только кровь врага, умершего в 3.2 м от Веры.
2. **СТИЛЬ — ЯСНОСТЬ.** Ранг стиля гасит голоса в голове; низкий ранг спавнит фантомов.
3. **ДВА СЛОЯ РЕАЛЬНОСТИ.** Таблетка переключает БЕЛУЮ и РЖАВУЮ версию уровня —
   и другой текст всех диалогов.
4. **НОВЕЛЛА НЕ ПАУЗИТ БОЙ.** Реплики Голосов идут в реальном времени, выбор — на таймере 6 с.
5. **СМЕРТЬ — ЭТО СЮЖЕТ.** Каждая смерть заводит новое дело в Архиве (твист №3).

## Вертикальный срез (в репозитории)

- Этаж 0 «ПАЛАТА №0» + этаж 1 «ПРИЁМНОЕ ОТДЕЛЕНИЕ», босс МЕДСЕСТРА ШВОВ ×3.
- Оружие: «ПЕРЧАТКА» (ближний бой/парирование), «КАПЕЛЬНИЦА» (револьвер + монеты),
  «ДЕФИБРИЛЛЯТОР» (дробовик с цепью), заготовки «ЛОБОТОМА» и «ЖАРА».
- Механики: рывок с i-frames, двойной прыжок, скольжение, ground slam,
  wall-run, монеты-рикошеты, парирование снарядов и таранов.
- Новелла: пролог, встреча с Лидой, твист №1 (дата смерти = дата выписки),
  голоса ДОКТОР/МАМА/СЕСТРА, анамнез, два слоя реальности, фантомы.
- 6 концовок полностью написаны (см. `docs/STORY.md`), экран концовок — в игре.

## Запуск

```bash
# Godot 4.4 или новее (включая 4.5/4.6):
godot --path .            # из редактора
godot --headless --path . --quit   # импорт ассетов в CI
```

Контента-ассетов (текстур/звуков) в проекте **нет намеренно**: всё генерируется
кодом в рантайме (процедурные текстуры, синтез звука, модели из примитивов).
Достаточно склонировать и открыть.

## Управление

Полная таблица: [`docs/CONTROLS.md`](docs/CONTROLS.md).
Коротко: `WASD` движение · `ЛКМ` атака · `ПКМ` парирование · `Shift` рывок ·
`Q` прыжок/истерика · `Ctrl` скольжение/slam · `R` монета · `T` таблетка · `E` взаимодействие.

## Структура

```
project.godot          конфиг, автозагрузки, инпут-мапы, физические слои
scenes/main.tscn       корневая сцена
scripts/
  main.gd              поток: меню → этажи → смерть/перестроение → концовки
  systems/             GameState, Style, Blood, Reality, SaveSystem, Dialogue, Audio, камера
  combat/              снаряды, парирование, монеты, оружие
  player/              контроллер Веры (движение/бой)
  enemies/             база врага + бестиарий (11 типов)
  factories/           процедурные модели персонажей, геометрия, материалы
  level/               сборка этажей из JSON, волны, триггеры комнат
  ui/                  HUD, VN-бокс, меню, анамнез, концовки
content/
  floors/              JSON-этажи (вертикальный срез: 0 и 1)
  dialogues/           JSON-диалоги (10 разговоров, включая пул голосов)
assets/portraits/      концепт-арты действующих лиц
docs/                  GDD, сюжет, персонажи, управление
```
