# УПРАВЛЕНИЕ

| Действие | Клавиша | Что делает |
|----------|---------|-----------|
| Движение | `WASD` / стрелки | относительно камеры (камера фиксирована, как в Isaac) |
| Прыжок / двойной | `Q` / `Space` | двойной = «истерика» (+40 стиля) |
| Рывок | `Shift` / `F` | i-frames; в воздухе тратит воздушный заряд |
| Скольжение | `Ctrl` | хитбокс ниже; в воздухе = ground slam |
| Slide-jump | `Ctrl` → `Q` | +35% длины прыжка |
| Удар / выстрел | `ЛКМ` | на «ПЕРЧАТКЕ»/«ЛОБОТОМЕ» — ближний бой, иначе — огонь |
| Парирование | `ПКМ` | окно 0.22 с; снаряд летит обратно с ×3 уроном |
| Монета | `R` | подброс монеты; выстрел по монете = рикошет-крит |
| Перезарядка | `R` | на оружии с барабаном |
| Таблетка | `T` | переключение БЕЛЫЙ ↔ РЖАВЫЙ слой (4 с морфа, неуязвимость) |
| Крик | `G` | оглушает врагов в радиусе 5.5 м, отпугивает (перезарядка 7 с) |
| Взаимодействие | `E` | двери, лифт, подписи, мел |
| Оружие 1–4 | `1`–`4` | «ПЕРЧАТКА», «КАПЕЛЬНИЦА», «ДЕФИБРИЛЛЯТОР», «ЛОБОТОМ» |
| Альт. оружие | `Tab` | цикл по открытым слотам |
| Анамнез | `Tab` в бою недоступен — см. меню паузы | медицинская карта: страницы, теги, персонажи |
| Пауза | `Esc` | сохранение, выход в меню |
| Выбор реплики | `1`–`4` | в диалогах; не ответил за 6 с = «МОЛЧАТЬ» |
| Дальше по диалогу | `Space` / `E` | раскрыть текст / следующий узел |

## Правила, которые игра не объясняет прямо

1. **Кровь = здоровье.** Лечат только враги, умершие в радиусе 3.2 м.
2. **Стиль не терпит повторов.** Одно и то же действие подряд даёт всё меньше очков.
3. **Остановка = гниль.** 4 секунды без стиля — счётчик сгорает.
4. **Ранг ≤ C — галлюцинации.** Появляются ФАНТОМЫ, экран гниёт, голоса возвращаются.
5. **Парирование лечит страх.** Каждое парирование даёт короткий неуязвимый кадр.
6. **Монеты ×4** — самая дорогая комбинация игры (+1200 стиля).
7. **Сохранение = процедура.** Каждая смерть создаёт новое дело в Архиве.
